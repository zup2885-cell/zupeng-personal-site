# 小怡拍摄助手

小怡说车的拍前准备、现场镜头记录和收工交接。纯静态网页，记录保存在当前浏览器，不需要构建，也没有账号、统计或云同步。

## 本地打开

在项目根目录启动任意静态服务器，然后用浏览器访问。不要直接双击 `index.html`，页面使用 ES Module，需要通过 HTTP 打开。

```bash
python3 -m http.server 47321
```

打开 [http://127.0.0.1:47321/](http://127.0.0.1:47321/)。

逻辑检查：

```bash
node --test test/logic.test.mjs
```

## 这次改了什么

- 界面改成剪纸分层：暖黄纸卡叠在蓝色峡谷上，项目卡、镜头卡、状态条和表单都坐在有框的纸层里。画框内是自绘的车与协作小景，没有外链图片。交互和数据结构没有改。
- Service Worker 缓存名更新为 `xiaoyi-static-v8`，样式、图标和纸片插画更新后，已打开过旧版的浏览器会改用新文件。
- 正文字号整体加大：根字号 16px，眉题、日期、标签、说明、进度、底栏和按钮等小字大约加大 2px。大标题仍维持原来的层级。
- 整张项目卡片可点进项目，也可以用键盘进入。右上角菜单（复制、备份、删除）不会把项目打开。

- 车辆年款、配置、车型从空白第一次填上，不再当成「车辆变更」，也不会把全部镜头和资料标成需重查。只有原先已经写过的内容被改掉或清空，才需要重新确认。
- 还没拍的必拍镜头，不再同时出现「必拍未拍」和「关联内容变更，需重查」两条待办。两条合成一条。
- 出发检查清单的分类会记住展开状态。连续勾选时，分类不再突然合上。
- 交接页可以额外下载 Markdown 交接单。素材文件名、素材位置、优选条次放在全文前面的速查表里，也放在每个镜头小节的开头。原来的文字交接单 `.txt` 仍然保留。
- 窄屏拍摄：状态按钮更高，上一镜/下一镜和取消、恢复靠近拇指；镜头清单收成一行横滑，侧栏改到底栏，不再占左侧。桌面宽屏仍是左侧栏和原来的镜头列表。
- 取消镜头默认折叠在「已取消」里。必拍取消仍要写原因，并保留一条待办；选拍可直接「跳过此镜头」（默认原因「现场跳过」），不进入待办。点「恢复此镜头」或任一状态都能恢复。
- 去掉了旧托管页面注入的脚本，仓库里只保留应用本身。
